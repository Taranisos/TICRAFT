# TICRAFT
Minecraft for the TI 84 Evo.

Install:
Download TICRAFT.py and all the assets.
Send them via connectEVO and don't forget to set the assets in archive.


Features:
10 Different blocks: air, grass, stone, oak_log, oak_planks, oak_leaves, sand, glass, water.
The world is a 2D side-view 999 blocks wide and a height of 8 blocks.

Graphics modes:
16x16
Textures from Minecraft.

Know issues:
-At the barrier between chunks 0 and 1, blocks won't render correctly if going right.
-It's slow.

Have fun!
